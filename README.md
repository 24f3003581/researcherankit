<summary><b>📁 Apfsmounter-rw — Cross-Platform Apple File System Driver</b></summary>
<br/>

A high-performance C++ systems application designed to inspect, parse, and mount Apple File System (APFS) formatted physical drives and DMG disk images with read/write I/O capabilities. Analyzes container superblocks, checkpoint maps, object maps (omap), and directory record B-Trees to achieve forensic-grade data recovery and interoperability on non-Apple operating systems.

**Tech:** C++ · POSIX Systems Programming · File System Forensics · APFS B-Trees · Hex Demultiplexing · CMake
